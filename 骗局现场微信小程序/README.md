# 骗局现场 微信小程序首版

这是原生微信小程序工程，不包含 PC 端页面或 Web 打包层。

## 已实现

- 案件大厅：30 个案例故事，均绑定南京反诈中心素材包中的原文标题、日期和链接。
- 单人模式《倒带一下》：倒带、搜证、暂停节点、安全行动与案例复盘。
- 多人模式原型：五个身份视角、私有材料、共享线索、十分钟倒计时、身份投票和不同阵营结算。
- 可体验案例：兼职群里的提现门、退费群中的另一个人、内部票的另一张账单、起飞前的陌生来电。

## 导入微信开发者工具

1. 打开微信开发者工具，选择“导入项目”。
2. 选择本文件夹。
3. AppID 先使用测试号或导入时选择“不使用云服务”。工程当前使用 `touristappid`，可用于本地体验。
4. 编译后从“案件大厅”进入单人或多人模式。

## 当前边界

- 多人模式的其他座位、主持人和投票结果是本地规则模拟，未接入真实房间、语音、WebSocket 或大模型。
- 正式上线前需接入后端案例审核、用户身份、房间状态、实时通信和大模型网关。
- 游戏中的金币、付款与对话均为虚构演练，不读取真实通讯录、微信群、支付信息或验证码。

## 规则回归测试

在安装 Node.js 的环境中运行：

```bash
node tests/game-rules.test.js
```

该测试覆盖 30 个案件来源指针、样例关卡标记、单人倒带截断、多人线索公开、投票结算和超时判负。案例事实、游戏化改编与未来大模型发言必须遵循 `anti-fraud-case-governance` 的边界：未经审校的内容不能写成真实事实，且不得生成真实支付、验证码、账号或规避风控操作。
