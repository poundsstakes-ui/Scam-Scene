# 骗局现场

本仓库保存微信小程序原型及其本地 AI 主持人演示服务的源码。

- `骗局现场微信小程序/`：微信小程序、案件数据、美术资源和规则测试。
- `骗局现场AI服务/`：仅供本地演示的 AI 主持人服务、模型适配和测试。

在微信开发者工具中导入 `骗局现场微信小程序/`。AppID 和基础库版本以项目配置及开发者工具中的实际设置为准。本机个人配置文件不纳入仓库。

小程序的多人玩法目前是本地预设机器人原型，不是真人联机；本地 AI 服务未提供公网部署所需的身份认证与房间权限校验。模型密钥仅通过服务端环境变量配置，服务使用方法见 `骗局现场AI服务/README.md`。

在各自目录中运行测试：

```powershell
Get-ChildItem tests -Filter '*.test.js' | ForEach-Object { node $_.FullName; if ($LASTEXITCODE -ne 0) { throw $_.Name } }
```

AI 服务目录中的 `*.test.js` 可分别通过 `node 文件名` 执行。
